# ⚽ Tienda Fútbol

## 📖 Descripción

**Tienda Fútbol** es una tienda online dedicada a la venta de camisetas y botines de fútbol para apasionados del deporte. El proyecto ofrece una amplia variedad de productos inspirados en clubes y equipos reconocidos, combinando calidad, estilo y accesibilidad en una experiencia de compra sencilla e intuitiva.

Este proyecto fue desarrollado como parte del **Trabajo Práctico N.º 1** de la materia **Construcción de Interfaces de Usuario**.

## 📂 Instalación y ejecución

### Clonar el repositorio

```bash
git clone <URL_DEL_REPOSITORIO>
```

### Instalar dependencias

```bash
pnpm install
```

### Ejecutar el proyecto en local

```bash
pnpm run dev
```

```bash
pnpm run deployd
```

Una vez iniciado, abrir el navegador en la URL indicada por Vite.
